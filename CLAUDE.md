# CLAUDE.md

Central instructions for every Claude Code conversation working on ProSup. These rules apply to all work in this repository, regardless of the specific task.

## Project Structure

- ProSup is **one main website** and **one GitHub repository**. There is no separate staging site, mirror, or alternate version.
- All features must remain connected to the main ProSup website. Do not build features in isolation that aren't wired into the live site.
- Do not create duplicate websites or separate versions of ProSup.

## Working Rules

- Do not delete working code or features without clear, explicit permission from the user.
- Before making changes, inspect the existing code and identify all affected files.
- Reuse existing layouts, components, colours and styling — do not introduce new patterns when existing ones already solve the problem.
- All pages must work on desktop, tablet and mobile.
- Keep the existing GitHub and Vercel connection working. Do not change deployment configuration unless explicitly asked.
- Run tests and a production build after making changes.
- Fix any errors caused by the changes before considering the work done.
- Clearly explain what was changed when finished.

## Security

- Do not commit passwords, API keys, invoices, bank information or private data.
